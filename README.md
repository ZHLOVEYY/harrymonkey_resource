# harrymonkey_resource

**中文** | [English](README.en.md)

一个独立游戏开发者的实践记录：看到好的游戏技术，就在自己的环境里跑一遍，把结果、改进和能跑的代码留在这里。
再加上一些我自己觉得值得收藏的链接。

每一条都会写清楚**原出处**。我自己复现过的，附上我的效果视频、我的改进和可运行的工程；
没有复现的，只记录原帖、原文和作者的演示链接。

**AI 执行，我验收。** 代码和素材多数是 AI 按我的要求做的，但每一条我都看过成品、跑过工程、核对过数字才放上来。这不是一个批量生产 AI slop 的仓库。
